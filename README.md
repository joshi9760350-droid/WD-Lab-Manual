# Web Designing Workshop Lab - Aman Sharma

This repository contains the HTML/CSS/JavaScript implementations for Experiments 1-10 from the Web Designing Workshop (BCS-353) lab manual.

## Run locally
Open `index.html` in a browser.

## Structure
- `exp1_home.html` - Online bookstore home page
- `exp2_login.html` - Login page
- `exp3_catalogue.html` - Catalogue
- `exp4_cart.html` - Cart
- `exp5_registration.html` - Registration form
- `exp6_js_name_password.html` - JS name/password validation
- `exp7_js_email_phone.html` - JS email/phone validation
- `exp8_css.html` - CSS styling and background images
- `exp9_background_repeat_links.html` - background-repeat and link pseudo-classes
- `exp10_portfolio.html` - portfolio using HTML, CSS and JavaScript
- `assets/` - local SVG assets
